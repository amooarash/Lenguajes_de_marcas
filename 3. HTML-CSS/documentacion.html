Introducción

WeatherAPI es una API ficticia que permite consultar información meteorológica de diferentes ciudades.

Los desarrolladores pueden utilizar esta API para obtener datos del tiempo en sus aplicaciones.

Para más información, visita: Consultar documentación oficial sobre HTTP en MDN

Autenticación

Para utilizar WeatherAPI, los usuarios necesitan una clave de acceso llamada API Key.

Esta clave permite identificar al usuario y acceder a los servicios de la API.

Para conocer las recomendaciones de seguridad: Política de seguridad: recomendaciones OWASP para APIs

Endpoint de usuarios

Este endpoint permite consultar información de los usuarios registrados.

GET /usuarios

Devuelve una lista de usuarios.

GET /usuarios/1

Devuelve la información del usuario con ID 1.

Endpoint de ciudades

Este endpoint permite consultar información meteorológica de diferentes ciudades.

GET /ciudades

Devuelve una lista de ciudades disponibles.

GET /ciudades/1

Devuelve la información meteorológica de la ciudad con ID 1.
